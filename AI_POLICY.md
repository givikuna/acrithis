# AI Policy

AI Generated Files and Code must be marked accordingly.

## AI Usage

AI usage is allowed on this project (as the course allows it).
However, for the sake of code honesty, and academic honesty, I feel that it is necessary to actually show where and how it was used.

## Files

If a file is fully generated by AI it must include the following header in a multi-line comment:

```
Author: <Model Name>
```

If a file is not fully AI generated but in the range of 50-70% it must use this:

```
Majorly Assisted By: <Model Name>
```

If a file used less than 50% of AI it must simply mark the blocks, if no AI was used (or very little assistance), it does not require any tags.

It is also expected that this comment is to be accompanied by another multi-line comment explaining how the AI was used.

## Blocks

If a block (or a significant chunk of said block) of code is written or generated with AI it must include the following header in a multi-line comment right above the block:

```
Assisted By: <Model Name>
```

Or (if fully AI generated):

```
Written By: <Model Name>
```
